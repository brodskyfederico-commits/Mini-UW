Pico al cierre de fecha=max(0,B de cada cierre). Dentro de una fecha, el orden es desconocido: cota superior=max(0,B anterior+A de esa fecha); cota inferior=max(0,B anterior,B al cierre). El rango global va del pico de cierres a la máxima cota superior. No se interpreta el orden de la lista de eventos como orden intradía; no se supone que un cobro anterior esté disponible o autorizado para financiar un aporte futuro. Es un rango matemático del acumulado neto, no prueba de liquidez, compromiso o capital disponible. No se genera automáticamente dinero para cubrir un pico.

Dependencia de venta=cobro neto de venta/total de cobros si este último>0; sin cobros permanece indefinida, no0%. Cobros excluyendo venta=D−venta; brecha aritmética sin esos cobros=max(0,A−(D−venta)).
