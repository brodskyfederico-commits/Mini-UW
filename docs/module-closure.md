Cada módulo sólo puede marcarse cerrado con definición y fuentes trazables, dominio/convenciones completos, conflictos aplicables resueltos, validación independiente, integración de dependencias y revisión aplicable acreditada. Ver `module-closure.json`.

Esto no prueba las reglas del negocio, el código original ni el producto integrado. No calcular porcentaje global contando requisitos, documentos o pruebas. Full UW es una entrega final diferida, fuera del cierre inicial del Mini-UW, sin omitir revisión auténtica para avanzar a esa fase.
